# Obby PB Tracker

Personal best tracker and overlay for Roblox obby players. Windows only. Free. Your data stays on your PC.

**Download:** go to [Releases](https://github.com/tibeteast/Obby-PB-Tracker/releases/latest) and get `ObbyPBTracker-<version>-setup.exe`. The installed app updates itself.

Beta until 1.0.0. Not affiliated with Roblox Corporation.
